Verification flow:
Admin -> Employee -> Documents -> Verify / Import from DigiLocker
-> employee signs in / consents on DigiLocker

-> issued documents are shown
-> admin selects a document
-> HRMS downloads the issued document with Bearer authorization
-> verifies DigiLocker response HMAC when supplied
-> saves it with status Verified, source DigiLocker, URI and verified timestamp
-> Done closes the verification session and revokes the token.
