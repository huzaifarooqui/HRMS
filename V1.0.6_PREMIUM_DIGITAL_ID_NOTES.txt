GRSJ HRMS v1.0.6 - Premium Digital ID Card
Date: 14 August 2026

IMPLEMENTED
- Premium responsive front/back Digital Employee ID Card.
- Card Flip interaction for front/back viewing.
- Dynamic company logo/name and employee data from existing HRMS database.
- Employee photo with safe fallback.
- Active/Inactive status badge.
- Signed employee verification token using the existing Flask SECRET_KEY.
- QR code generated locally using the already-installed ReportLab package (no CDN/new dependency).
- Public verification page exposes only limited official identity/status fields.
- QR reflects live employee status from the database at verification time.
- Downloadable two-page PDF at standard CR80/PVC ID-card dimensions (85.60 x 53.98 mm).
- Front PDF: branding, photo, name, designation, employee ID, department, status.
- Back PDF: QR verification, login ID, joining date and company ownership notice.
- Sensitive personal fields (address/Aadhaar/PAN/phone) are not exposed on public verification page.
