# GRSJ HRMS v1.0.2 Maintenance Build

Implemented approved production changes:
- Proper favicon/PWA shortcut icons.
- Removed duplicate admin account/logout menu from top-right; sidebar remains authoritative.
- Manual attendance add/edit with audit reason/history table.
- Holiday add/edit/delete and current-month default calendar.
- Full Add Employee form with photo, parent mobile numbers, salary + target, dropdowns.
- Login ID format: First initial + Mother first-name initial + YYMMDD + random 2 digits.
- Check-in after configurable 10:30 threshold immediately marks Half Day.
- Mobile fixes for admin dashboard, departments, employee dashboard, My Profile and My Leaves.
- Google Translate popups suppressed with notranslate metadata.
- July 2026 XLSX attendance import available on Admin > Attendance; duplicate rows are preserved/not overwritten.
- Employees table has Add Docs shortcut.
- Leave decision uses dropdown.
- Employee attendance leaderboard.
- Long employee edit sessions no longer expire after five minutes (8-hour rolling session).
- State dropdown + PIN-assisted District/City dropdowns with manual fallback.
- Blood group and finite fields use dropdowns.
- Late arrival popup is locked until a reason is submitted and stored.
- Document model is DigiLocker-ready, but live verification is intentionally NOT marked active without official DigiLocker partner/API credentials and employee consent.

## Upgrade
1. Back up the current database and folder.
2. Stop Waitress.
3. Replace application files with this build while preserving `Server/.env` and uploaded files/database.
4. Start the app once. `schema.py` adds required columns/tables automatically without dropping existing data.
5. Go to Admin > Attendance and import the supplied July 2026 XLSX. Existing employee/date attendance rows are not overwritten.
6. Test Add Employee, Edit Employee, late check-in, attendance correction, holiday edit, and mobile layouts before final production sign-off.
